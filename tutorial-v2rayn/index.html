v2rayN Windows 安装与使用教程

直接回答：v2rayN 使用流程：GitHub 下载带内核的压缩包解压运行 → 「订阅分组」添加机场订阅链接并更新 → 服务器列表测延迟选节点（回车设为活动节点）→ 右下角图标菜单开启「自动配置系统代理」。

下载与安装

从 v2rayN 的 GitHub Releases 下载 v2rayN-windows-64-With-Core.zip（自带内核，省去单独配置），解压到独立英文路径文件夹（路径不要含中文和空格），运行 v2rayN.exe。首次启动会驻留任务栏右下角托盘。

杀毒软件可能误报内核文件，添加信任即可（前提：确认来源是官方 GitHub）。Windows 可能弹 SmartScreen，点「更多信息 → 仍要运行」。

导入订阅

  • 主菜单「订阅分组」→「订阅分组设置」→「添加」，粘贴机场订阅链接，填备注，确定；
  • 菜单「订阅分组」→「更新全部订阅（不通过代理）」；
  • 服务器列表出现全部节点即成功。

选择节点与开启代理

  • 全选节点，菜单「服务器」→「测试服务器真连接延迟」；
  • 选中延迟低的节点，回车（或右键「设为活动服务器」）；
  • 右下角托盘图标右键 →「系统代理」→「自动配置系统代理」；
  • 浏览器验证外网访问。

路由设置

托盘图标右键 →「路由」，常用三种：

  • 绕过大陆（Bypass mainland）：推荐，国内直连、国外走代理；
  • 全局（Global）：所有流量都走代理；
  • 需要更精细的按域名分流时，建议直接换用 Clash Verge Rev 的规则体系。

常见问题

订阅更新失败？先选一个可用节点改用「通过代理更新订阅」，或检查订阅链接是否过期，必要时登录机场后台获取最新链接。

部分软件不走代理？v2rayN 的系统代理不覆盖终端等程序，需要 TUN 模式（设置中开启）或手动配终端代理。

v2rayN 和 Clash Verge 怎么选？新手选 Clash Verge Rev，界面友好、规则分流开箱即用；v2rayN 的优势是协议支持全、配置自由度高，适合需要精细控制或调试节点的进阶用户。

v2rayN 支持哪些协议？通过 Xray/sing-box 内核支持 VMess、VLESS、Trojan、Shadowsocks、Hysteria2、TUIC 等几乎全部主流协议，这是它相对 Clash 系客户端的主要优势之一。
