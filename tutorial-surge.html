Surge 使用教程：macOS/iOS 旗舰客户端配置与分流

Surge 是什么

直接回答：Surge 是 macOS 和 iOS 平台上最知名的付费代理客户端之一，由个人开发者维护，以「规则系统强大 + 高度可定制」著称，被很多进阶用户视为代理客户端的标杆。它支持导入机场订阅，也支持 Shadowsocks、VLESS、VMess、Trojan、TUIC、Hysteria2 等主流协议。

与开源免费的 Clash 系相比，Surge 是商业闭源软件，付费买断，但换来的是更精细的规则引擎、更稳定的更新和更强的脚本扩展能力。它更适合愿意付费、追求极致控制力的用户。

维度SurgeClash 系
平台macOS / iOS全平台
授权付费买断多数免费开源
规则系统强，精细可控强，规则集生态成熟
脚本扩展支持 JavaScript 模块部分支持

下载与安装

  • macOS：在 Mac App Store 搜索「Surge」购买安装，或通过开发者官网购买。
  • iOS：在 App Store 搜索「Surge」购买安装。

Surge 是一次性买断（不同版本价格不同），购买后即可长期使用。安装完成后首次打开，按提示完成初始化即可。

导入机场订阅

  1. 登录机场官网，复制订阅链接。
  2. 打开 Surge，进入「配置」页面，点击「从 URL 下载配置」或「导入」。
  3. 粘贴机场订阅链接，Surge 会自动下载并解析节点。
  4. 导入成功后，在「策略组」中可以看到机场的节点列表。
提示：部分机场提供专门的 Surge 订阅格式，优先用 Surge 格式；如果只有通用订阅或 Clash 格式，Surge 也能导入，但可能需要手动调整部分策略组。

选择节点并连接

Surge 的节点选择通过「策略组」完成。策略组是一组节点的集合，常见的有：

  • 代理策略组：决定默认走哪个节点，可手动选择或设为自动测速。
  • 分流策略组：按规则把不同流量分配到不同节点（如流媒体走特定地区节点）。

连接时，进入「首页」或「策略组」，选择一个节点，打开「系统代理」或「增强模式」开关即可。Surge 的「增强模式」类似 TUN，能接管不支持系统代理的应用。

规则分流怎么配

Surge 的规则系统是它的核心优势，配置思路如下：

规则类型作用示例
DIRECT直连，不走代理国内网站、App
PROXY走代理节点国外网站
REJECT拒绝连接广告、跟踪域名
策略组按规则分配流媒体走指定地区

日常使用，机场提供的订阅通常已内置一套规则，导入即可用。进阶用户可以导入第三方规则集（如 GeoIP、GeoSite），或用 Surge 的 JavaScript 模块实现更复杂的分流和重写。

Surge 版本与模块扩展

Surge 分 Mac 和 iOS 两个版本，功能侧重点略有不同：Mac 版支持更完整的增强模式、脚本和网络调试，适合在电脑上深度使用；iOS 版面向移动场景，规则和分流同样强大。两个版本需分别购买。

Surge 的模块（Module）和脚本（Script）是它的进阶玩法：

  • 模块：把一组规则打包成可复用的模块，一键开关，常用于广告拦截、去重定向等。
  • 脚本：用 JavaScript 实现请求改写、响应修改，比如自动签到、解锁检测等。

对普通机场用户，模块和脚本不是必学的；导入机场订阅、选好节点、开增强模式，就已经能完成绝大多数日常需求。进阶玩法可以等熟悉基础后再慢慢探索。

常见问题排查

问题可能原因解决办法
订阅导入失败链接过期或格式不兼容重新复制链接，换 Surge 格式
节点连不上节点失效或协议不匹配换节点或更新订阅
连上但无法上网规则或系统代理异常检查策略组，重启 Surge
部分应用不走代理不支持系统代理开启增强模式
速度慢节点拥堵或本地网络差换低延迟节点，避开晚高峰

Surge 的上手门槛略高于 Clash，但一旦熟悉它的策略组和规则逻辑，就能实现非常精细的流量控制。对追求「每个流量走哪里都自己说了算」的用户，Surge 是值得付费的选择。
