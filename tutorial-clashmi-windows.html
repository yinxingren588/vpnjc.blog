ClashMi Windows 绿色版使用与订阅导入

ClashMi 除了 iOS 版，还有 Windows 绿色版。所谓绿色版就是不用安装，下载一个 zip 压缩包，解压后直接运行 exe 就能使用。这对于不方便安装软件的公司电脑、或不想在系统里留安装记录的用户来说很方便。本文演示从下载、解压、处理 SmartScreen 拦截、导入订阅到开启连接的完整流程。

测试环境Windows 10 22H2（64 位），ClashMi Windows 版本 1.3.0（2026-05 更新），测试使用无忧链接订阅链接。解压工具为 7-Zip。

第一步：下载与解压

ClashMi Windows 版不在 Microsoft Store 上架，需要从 GitHub Releases 页面下载。访问 ClashMi 的 GitHub 仓库 → Releases → 找到最新版本 → 下载 ClashMi-windows-x64.zip（约 15MB）。

下载后，右键点击 zip 文件 → 「解压到 ClashMi-windows-x64\」。解压后的文件夹里只有一个 ClashMi.exe 和一个 resources 文件夹。不需要任何安装步骤。

建议将解压后的文件夹放在固定位置（如 D:\Tools\ClashMi\），不要放在桌面或 Downloads 文件夹里，否则清理时容易误删。可以创建一个快捷方式到桌面方便打开。

第二步：处理 SmartScreen 拦截

双击 ClashMi.exe 运行时，Windows 可能弹出 SmartScreen 拦截页面，提示「Windows 已保护你的电脑」。这是因为 ClashMi 没有购买代码签名证书（开源软件通常不会买）。

处理方法：在 SmartScreen 弹窗中点击「更多信息」→ 此时会出现「仍要运行」按钮 → 点击即可继续运行。这个操作不会影响系统安全，ClashMi 是开源软件，代码可以在 GitHub 上审查。

如果 Windows Defender 直接删除了文件，需要在「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」中找到被隔离的 ClashMi.exe，选择「还原」或「允许在设备上运行」。然后在文件夹中重新运行。

首次运行时，ClashMi 可能会请求管理员权限（UAC 弹窗），点击「是」。管理员权限是为了设置系统代理和 Tun 模式所需，不影响系统安全。

第三步：添加机场订阅链接

ClashMi Windows 版的界面与 iOS 版类似，左侧有三个标签：「配置」「代理」「设置」。点击「配置」标签 → 右上角「+」按钮 → 选择「从 URL 导入」。

在输入框中粘贴你的机场订阅链接（Clash 格式），点击「下载」。ClashMi 会自动下载配置文件并解析。成功后配置页面会出现一条配置项，显示节点数量和更新时间。

你也可以选择「从文件导入」，如果你有本地 Clash 配置文件（.yaml）的话。但对于机场用户来说，URL 导入是最方便的方式——节点更新时只需要点击「更新」按钮就能自动同步。

订阅链接在机场官网的「用户中心」或「我的订阅」页面可以找到。格式类似 https://example.com/api/v1/client/subscribe?token=xxxxx。注意不要把链接分享给别人，否则别人可以使用你的流量。

第四步：选择节点与开启连接

切换到「代理」标签页，可以看到按地区分组的节点列表。点击任意节点选中它（推荐先选香港节点）。然后点击主界面顶部的大开关按钮开启连接。

开启连接后，ClashMi 会设置系统代理（HTTP 代理模式），所有支持系统代理的应用（浏览器、微信等）都会走代理。状态栏不会显示 VPN 图标（因为不是 VPN 模式），但你可以打开浏览器访问 google.com 验证连接是否正常。

如果需要全局代理（包括不遵守系统代理的应用），可以在「设置」中开启「Tun 模式」。Tun 模式需要管理员权限，开启后所有流量都会走 ClashMi。但 Tun 模式可能影响某些本地服务（如局域网文件共享），按需使用。

常见问题

Q：ClashMi Windows 版和 Clash Verge 有什么区别？

ClashMi 更轻量，界面更简洁，适合新手。Clash Verge 功能更丰富，支持更多高级设置（如自定义规则、Profile 切换、日志查看）。如果你只是简单使用机场订阅，ClashMi 足够了；如果你需要精细控制，推荐 Clash Verge。

Q：为什么运行后没有网络？

检查以下几点：①节点是否选中了（代理页面应该高亮显示一个节点）；②订阅链接是否下载成功（配置页面应该显示节点数量大于 0）；③是否被防火墙拦截（临时关闭防火墙试试）；④如果开了 Tun 模式但没权限，试试以管理员身份运行 ClashMi.exe。

Q：如何开机自启？

在「设置」页面可以开启「开机自启动」选项。ClashMi 会在 Windows 注册表中添加自启动项。如果你用绿色版担心被清理，也可以手动在任务管理器 → 启动选项卡中添加快捷方式。

Q：支持 Windows 7 吗？

不支持。ClashMi Windows 版需要 Windows 10 1809 或更高版本，因为依赖新版 Windows 的网络 API。Windows 7 用户建议使用 v2rayN 或 Clash for Windows。

Q：杀毒软件报毒怎么办？

这是开源软件的常见问题——没有购买代码签名证书，杀毒软件会启发式扫描报毒。你可以在杀毒软件中将 ClashMi.exe 添加到白名单/信任列表。如果你对安全性有疑虑，可以自行从 GitHub 源码编译。
