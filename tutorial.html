新手推荐路径

按这个顺序走，四步能用

第一次用机场，最容易卡在三个地方：订阅链接复制错、客户端没接管代理、连上了却打不开某些网站。按「导入订阅 → 装客户端 → 测速 → 按症状排查」的顺序走一遍，基本能覆盖 90% 的入门问题。已经能正常用的，直接跳到下面的分组查具体需求。

第 1 步 拿到订阅链接，先确认格式对不对 机场后台复制 https 链接，客户端「添加配置 / 导入订阅」粘贴保存，自动拉节点。 第 2 步 装一个能用的客户端 Windows / macOS 用 Clash Verge Rev，iOS 用 Shadowrocket 或 ClashMi，Android 用 Clash Meta。 第 3 步 测一下延迟和速度，别拿错节点 先用客户端自带延迟测试筛一轮，再批量测速，晚高峰复测一次才准。 第 4 步 连不上就按症状排查 五类症状一次定位：全节点连不上 / 订阅更新失败 / 晚高峰变慢 / ChatGPT 打不开 / 更新后失效。
