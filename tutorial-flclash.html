FlClash 使用教程：全平台订阅导入与分流

FlClash 是什么

直接回答：FlClash 是一款免费开源的跨平台代理客户端，基于 Flutter 开发、使用 mihomo（Clash Meta）内核，支持 Android、Windows、macOS、Linux 等平台，可导入机场订阅使用。它的特点是界面现代、跨平台一致，是 Clash 系里较新的一个选择。

维度说明
内核mihomo（Clash Meta）
平台Android / Windows / macOS / Linux
价格免费开源
协议支持VLESS/VMess/Trojan/Shadowsocks/Hysteria2 等
特色跨平台一致体验、订阅管理、规则分流

下载与安装

FlClash 各平台安装方式：

  • Android：下载 APK 安装。
  • Windows / macOS / Linux：从 GitHub Releases 页面下载对应平台的安装包。

安装完成后首次打开，按提示完成初始化即可，无需注册账号。

导入机场订阅

  1. 登录机场官网，复制订阅链接。
  2. 打开 FlClash，进入「订阅」或「配置」页面，点击「添加订阅」。
  3. 粘贴订阅链接，选择链接类型（一般为「订阅链接」，部分机场提供 Clash 格式）。
  4. 点击确定，等待客户端拉取节点，完成后节点会出现在列表中。
提示：订阅拉取失败时，先检查链接是否完整、是否过期，再确认本地网络能否访问订阅地址。FlClash 支持定时自动更新订阅。

选择节点并连接

节点同步后，回到主界面选择一个节点点击即可连接。选节点看两点：

  • 看地区：解锁特定流媒体或 AI 服务时，选对应地区节点。
  • 看延迟：客户端内置测速，优先选延迟低、丢包少的节点。

连接成功后，系统代理自动生效，浏览器和大部分应用自动走代理。需要所有流量（含不支持系统代理的应用）走代理时，在设置中开启 TUN 模式。

分流规则怎么配

模式行为适用场景
规则模式国内直连、国外走代理日常使用（推荐）
全局模式全部流量走代理临时使用、测试节点
直连模式全部流量直连临时关闭代理

日常推荐「规则模式」，国内网站直连、国外网站走代理。机场订阅通常已内置规则，导入即可用。

FlClash 与其他客户端对比

Clash 系客户端很多，FlClash 的定位是「跨平台一致体验」：

  • FlClash：跨平台一致、界面现代，适合多端统一体验。
  • Clash Verge Rev：跨平台、功能全，生态成熟。
  • ClashX Meta：仅 macOS，菜单栏轻量。
  • NekoBox/Nekoray：手机/桌面分体，简洁。

如果你在多平台间切换、希望体验一致，FlClash 是合适的选择；只用一个平台的话，选该平台最顺手的即可。

进阶功能

熟悉基础后，可以试试 FlClash 的进阶功能：

  • 规则集管理：导入 GeoIP、GeoSite 规则集，精细控制分流。
  • 节点分组：多机场订阅分组建，切换机场一键换组。
  • TUN 模式：接管全部流量，含不支持系统代理的应用。

常见问题排查

问题可能原因解决办法
订阅导入失败链接过期或复制不全重新复制链接，检查网络
节点连不上节点失效或协议不匹配换节点或更新订阅
连上但无法上网规则或系统代理异常切换规则模式，重启客户端
部分应用不走代理不支持系统代理开启 TUN 模式
速度慢节点拥堵或本地网络差换低延迟节点，避开晚高峰

FlClash 作为较新的开源 Clash 客户端，界面现代、跨平台体验一致，导入订阅后上手很快。如果你喜欢一致的跨平台体验，FlClash 值得一试。

小结

FlClash 的核心优势是「跨平台一致」和「界面现代」。导入订阅、选节点、开规则模式三步就能用，进阶用户还能通过规则集和 TUN 模式精细控制。对于想在不同设备上获得一致翻墙体验的用户，FlClash 是一个省心且免费的选择。
