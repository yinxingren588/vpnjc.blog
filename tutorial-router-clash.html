路由器翻墙教程：OpenClash/PassWall 全屋科学上网

为什么要在路由器上翻墙

手机、电脑装客户端，一台一台配，累；电视、游戏机、智能家居根本装不了客户端。把翻墙这件事搬到路由器上，一次配置，全家设备自动走代理，这就是「全屋科学上网」的核心价值。本文讲 OpenWrt 下最常用的两套方案：OpenClash 和 PassWall。

OpenClash 和 PassWall 是什么

两者都是运行在 OpenWrt 路由器系统上的翻墙插件，区别在定位：

维度OpenClashPassWall
内核Clash 内核多协议（Xray/SS/Trojan 等）
分流规则强，Clash 规则集中，内置分流
配置难度较高较低
资源占用较高（建议 512MB 内存）较低
适合人群追求精细分流的进阶用户资源有限、求稳的用户

前提条件

在路由器上翻墙，先要满足三个条件：

  1. 路由器能刷 OpenWrt：硬路由需要刷入 OpenWrt 固件，或直接使用软路由（x86 小主机装 OpenWrt）。
  2. 有足够的性能：OpenClash 建议 512MB 以上内存，PassWall 要求较低；CPU 决定加密吞吐，弱路由跑不满带宽。
  3. 有可用的机场订阅：路由器翻墙同样需要节点，机场订阅链接是配置的核心输入。
提示：硬路由（如部分小米、GL.iNet 型号）刷 OpenWrt 有风险，动手前务必确认固件兼容性；不折腾的话，直接买一台软路由最省心。

OpenClash 配置步骤

  1. 登录 OpenWrt 后台，安装 OpenClash 插件（通过软件包或离线包）。
  2. 打开 OpenClash，进入「配置订阅」，粘贴机场订阅链接，设置自动更新。
  3. 在「配置文件」中生成或导入 Clash 配置，选择订阅对应的配置。
  4. 启用 OpenClash，选择节点，开启系统代理或 TUN 模式。
  5. 在「分流设置」中启用规则分流，国内直连、国外走代理。

PassWall 配置步骤

  1. 安装 PassWall 插件。
  2. 进入「节点列表」，添加节点或直接导入机场订阅。
  3. 在「基本设置」中启用主开关，选择默认节点。
  4. 配置「分流规则」，选择国内直连 + 国外走代理的模式。
  5. 保存应用，全家设备即可自动走代理。

怎么选：OpenClash 还是 PassWall

  • 想精细分流、喜欢折腾：选 OpenClash，Clash 规则集生态成熟，可按域名、按应用精准分流。
  • 路由器性能一般、求稳：选 PassWall，资源占用低，配置直观，适合弱路由或新手。
  • 两者都要：部分软路由性能充足，可同时装两者，按需切换。

软路由怎么选

软路由的性能直接决定翻墙速度和稳定性，选购时看三点：

  • CPU：加密解密吃 CPU，选性能强的处理器（如 N100、J4125 等常见软路由 CPU），弱 CPU 跑不满带宽。
  • 内存：OpenClash 建议 512MB 以上，内存越大越从容。
  • 网口：至少双千兆网口（一进一出），多网口可做更多玩法。

预算有限的话，先选一台双千兆、N100 级别的入门软路由即可满足绝大多数家庭需求，不必盲目追高配。

DNS 设置别忽略

路由器翻墙最容易踩的坑是 DNS 污染。翻墙插件通常自带 DNS 分流，配置时注意：

  • 开启 DNS 分流：国内域名走国内 DNS，国外域名走代理 DNS，避免解析被污染。
  • 避免 DNS 冲突：不要让路由器主 DNS 和插件 DNS 互相干扰，统一交给插件管理。
  • 测试解析：配置完成后，用一个国外网站验证 DNS 是否正常解析、能否正常访问。
